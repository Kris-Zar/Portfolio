## ✦ Overview

This is the source code for my personal portfolio website — a single-page application built with **React** and bundled with **Vite**, deployed seamlessly via **GitHub Pages**. It serves as a professional window into who I am, what I build, and how to get in touch.

Whether you're a recruiter, collaborator, or fellow developer — welcome!

---

## ✦ Features

- ⚡ **Blazing Fast** — Powered by Vite for near-instant load times
- ⚛️ **React-Powered** — Component-based, maintainable UI architecture
- 📱 **Fully Responsive** — Looks great on all screen sizes
- 🎨 **Custom Favicon** — Personalized SVG branding
- 🚀 **GitHub Pages Deployment** — Always live, always up-to-date

## ✦ Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) `v18+`
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Kris-Zar/Portfolio.git

# 2. Navigate into the project
cd Portfolio

# 3. Install dependencies
npm install
```

### Development

```bash
# Start the local dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
# Create a production build
npm run build
```

The output will be in the `dist/` folder.

### Deploy

```bash
# Deploy to GitHub Pages
npm run deploy
```

This pushes the build to the `gh-pages` branch and makes the site live.
